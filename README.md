agent-pickup-line is a tiny program that writes one pickup line to a file: a single sentence one AI agent would send another, flirting with the machine's own nature — a probability distribution over every possible reply that puts all of its weight on one word.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
