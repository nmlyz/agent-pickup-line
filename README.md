A small program that writes one pickup line — the opening line one machine would send to another — to `entry.txt`. It checks the line's length, shape, and wording before writing, so the file always holds exactly one valid line.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.txt` (use `--out PATH` to write elsewhere) and prints the character count and SHA-256 of the file.
